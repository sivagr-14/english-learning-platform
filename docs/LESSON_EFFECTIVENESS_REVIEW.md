# Eight-section lesson and usability review

Reviewed 2026-10-03. Scope: all 12 repository starter lessons, the simplified-v2
schema and quality checks, generation instructions, quick lesson, detailed lesson,
practice, review and navigation screens. This is a repository review, not an audit
of the learner's local database or 40,000 generated entries. Those are unavailable.

## Verdict

Keep the eight sections. They provide a strong reference structure, but their
presence alone does not demonstrate natural language quality or mastery. The
current material is strongest at explanation, collocation and recognition. It
needs more demanding retrieval, interaction, register choice and transfer to new
situations. Aim for appropriate, intelligible and flexible communication; no
lesson layout or word count can guarantee native-like performance.

The new UI makes the first visit short: contextual meaning, conversation, personal
response, then optional detail. All eight sections remain reachable through a
section navigator, with stacked fields on phones. The reference example is an
example, not an answer key or automatic evaluation of the learner's response.

## Review of every section

| Section | What to retain | Priority improvement and acceptance criterion |
| --- | --- | --- |
| 1. Overview | Plain meaning, Tamil support, core idea, tone and register | One contextual sense per entry. Label dialect/register only with support. Avoid mixing emotional, material or interpersonal senses simply because spelling matches. |
| 2. Meaning in Context | Source sentence and a contextual paraphrase | Explain what the speaker intends and why this expression fits here. Preserve authentic source evidence; clearly distinguish authored examples from source quotations. |
| 3. Usage Guide | When to use and when not to use | Name audience, relationship, purpose and social risk. Give a safer alternative when wording is too formal, direct or idiomatic. Avoid categorical prohibitions where usage is merely less typical. |
| 4. Patterns & Collocations | Reusable patterns and useful word partners | Check each pattern for grammar and meaningful substitution. Include article/preposition, complement, countability or clause punctuation when relevant. Do not combine incompatible structures into one slash-separated formula. |
| 5. Natural Examples | Varied contexts and short conversations | Normally use 2–4 purposeful turns with a reaction or next action. For workplace expressions, show a realistic spoken update and written message where natural. Keep every example in the entry's sense. Include a plain alternative; elaborate wording is not inherently better. |
| 6. Mistakes & Differences | Correction and comparison | Use plausible learner mistakes and explain the consequence. Distinguish wrong grammar from unusual phrasing, register mismatch or a different meaning. Compare close alternatives in the same situation. |
| 7. Memory & Practice | Recall, recognition, production and memory cue | Ask for meaning-to-expression retrieval and a response with an audience and purpose. Use plausible distractors. A memory cue supports practice but does not replace it. Model responses must not imply only one sentence is correct. Revisit on later days and vary the context. |
| 8. Advanced Nuance | Social meaning, implication and finer distinctions | Prioritize a useful pragmatic contrast over obscure trivia. Explain when the distinction changes the learner's choice. Refer to other meanings without teaching them as part of this entry. |

## Concrete findings in the starter set

These need a reviewed content correction/versioned import before certifying the
starter set as an editorial gold standard. This UI change does not rewrite stored
lessons or reassign sense ranks.

- **straightforward:** the source describes an uncomplicated process, but the
  meaning, patterns, examples and production task also teach an honest/direct
  person. Separate the senses under the established sense identity policy.
- **a compelling argument:** “A valid argument is logically sound” conflates
  validity with soundness. Correct that distinction; persuasive force is separate
  from either. Its production task also permits an argument that never uses the
  target expression; require the learner to describe/evaluate an argument with it.
- **manageable:** “become / remain / make + something + manageable” merges two
  different structures. Use “something becomes/remains manageable” and “make
  something manageable.” “Do not use ... when ... completely effortless” is too
  absolute; the word does not require a minimum difficulty.
- **practical:** “practical experience” introduces the hands-on/actual-experience
  sense alongside useful/realistic. Review sense boundaries. Move the less useful
  practical/practicable distinction to optional nuance if it is retained; prioritize
  realistic usage in the core mistake exercise.
- **resilient:** human recovery, systems and material properties are grouped.
  Review the contextual scope, keep the human-recovery lesson focused, and make
  a separate entry where the meaning changes rather than only the application.
- **overwhelmed:** inability to cope and strong positive emotion are mixed. Review
  as separate senses; preserve a cross-reference to the positive sense.
- **come to terms with:** good contextual explanation and contrast with accept.
  Add a response/reaction and an optional fictional scenario so personal disclosure
  is not needed. Avoid overstating emotional struggle as necessary in all usages.
- **to no avail:** label its relatively formal/narrative flavor and show the ordinary
  alternative “but it didn’t help.” Partial success can still coexist with failure
  to achieve the intended goal; soften the absolute exclusion.
- **draw a conclusion:** good contrast with making a decision. Replace obvious
  “evidence versus rumor” recognition with two plausible uses of the expression;
  this tests language understanding rather than general reasoning alone.
- **substantiate:** useful distinction between evidence and explanation. Replace
  the predictable unsupported-opinion question with a small evidence scenario and
  an actual professional follow-up. Have bilingual review check that Tamil does
  not imply stronger proof than the English sense.
- **by and large:** strong exception-bearing dialogue. Revise “Do not use ... for
  an absolute claim with no exceptions”: the expression allows exceptions, but
  need not assert that actual exceptions exist.
- **at odds with:** useful evidence/policy contrasts. Add the interpersonal effect
  of calling a colleague's view incompatible and a softer professional alternative.

Across the 12 samples, most conversations have only two turns, many recognition
choices are obvious, and no per-entry corpus citation verifies frequency/CEFR.
Do not treat frequency labels as measured corpus results. A qualified bilingual
review is still needed for Tamil. I have not certified every translation.

## Additional materials needed for broader fluency

1. A reviewed pilot spanning words, phrases, idioms, collocations, connectors and
   professional communication; include trade-offs, priorities, strategy, principles,
   clarification, disagreement, requests, setbacks and follow-up.
2. Multi-turn scenarios with real communicative goals: negotiate a deadline,
   explain a trade-off, summarize a decision and confirm the next action. Add
   longer listening/reading passages and retelling beyond individual entry cards.
3. Pronunciation materials with stress, chunking, connected speech and supported
   regional variation. Current audio is synthetic browser playback and local
   recording, not evaluated pronunciation or professionally recorded speech.
4. Plausible recognition distractors, production rubrics and several acceptable
   responses, with later-day retrieval and changed-context transfer.
5. A1/A2 foundation-gap coverage using a versioned selection contract. Existing
   B1–C2 collection rules do not establish a complete foundation curriculum.
6. Calibrated human/editorial assessment of saved responses and genuine
   conversational interaction. Self-ratings are useful evidence, not certification.

## Evidence and limits

Dunlosky et al. (2013), *Improving Students' Learning With Effective Learning
Techniques*, rates practice testing and distributed practice highly across the
reviewed settings. This supports retrieval and later revisiting, but is not direct
proof that this app produces fluency: https://doi.org/10.1177/1529100612453266

Nation (2007), *The Four Strands*, proposes balancing meaning-focused input,
meaning-focused output, deliberate language learning and fluency development.
This motivates passages, conversations and familiar-language practice alongside
entry study; it does not establish an app-specific optimum:
https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/2007-Four-strands.pdf

## Release review

The redesigned shell covers every authenticated route; the login, registration
and email-link entry screens share the same visual system. Specific improvements
include mobile navigation, keyboard skip/focus controls, quiet account maintenance,
responsive lesson fields, readable result cards, explicit retry states, descriptive
form errors and reduced-motion support. Automated checks are scoped evidence,
not a blanket WCAG certification. Validate installed-app behavior with real data,
keyboard and screen-reader use before claiming comprehensive accessibility.
